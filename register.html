Quick manual

  1. Clone the repo locally.
  2. Import database/schema.sql into MySQL.
  3. Place the project in your webserver's document root (e.g., C:/xampp/htdocs/RemoteTeamPro).
  4. Start XAMPP (Apache + MySQL) and open the local registration link above.
